# VoxoraTTS — descargas públicas

Este repositorio aloja exclusivamente los instaladores y metadatos de actualización de Voxora.

## Instalar

Abre **Releases**, descarga `Voxora-Setup-x.y.z.exe` y ejecuta el instalador. Desde la versión 0.10.0, Voxora puede descargar, verificar e instalar futuras actualizaciones desde la propia aplicación.

## Archivos de cada release

- `Voxora-Setup-x.y.z.exe`: instalador de Windows.
- `Voxora-Setup-x.y.z.exe.blockmap`: descarga incremental.
- `latest.yml`: versión, tamaño y SHA-512 que la aplicación verifica antes de instalar.

El código fuente y los secretos de las integraciones no se publican en este repositorio.
